# Aussie data Actors for Apify

Small, single-purpose Apify Actors for Australian data. Each folder is one Actor.

- `au-abn-acn-validator`: bulk ABN and ACN check digit validator (offline).
- `rba-rates-json`: RBA exchange rates and cash rate decisions as JSON.

Build on Apify from Git: Actor > Source > Git repository, URL `https://github.com/<user>/<repo>#main:au-abn-acn-validator` (or `:rba-rates-json`).

Run tests: `cd <actor> && npm install && npm test`.
